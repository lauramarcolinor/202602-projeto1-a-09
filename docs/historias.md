## Critérios de aceite

### HU01 — Resumo da primeira fatura

- [ ] O valor total da primeira fatura aparece com destaque.
- [ ] O status da cobrança é apresentado de forma clara.
- [ ] A tela permite avançar para os detalhes ou formas de pagamento.

### HU02 — Composição e vencimento

- [ ] A tela apresenta a composição da cobrança em linguagem simples.
- [ ] A data de vencimento aparece com destaque.
- [ ] O cliente consegue identificar o que precisa pagar e até quando.

### HU03 — Formas de pagamento

- [ ] As formas de pagamento disponíveis são apresentadas claramente.
- [ ] O PIX aparece como uma opção de destaque.
- [ ] O cliente consegue selecionar uma forma de pagamento.

### HU04 — Pagamento via PIX

- [ ] A tela apresenta as instruções necessárias para pagar via PIX.
- [ ] O cliente consegue visualizar ou copiar o código/identificador fictício do PIX.
- [ ] A tela informa o que fazer após concluir o pagamento.

### HU05 — Lembrete de vencimento

- [ ] A tela informa a data de vencimento da fatura.
- [ ] O cliente consegue escolher ou confirmar o recebimento de um lembrete.
- [ ] A confirmação do lembrete aparece após a ação.

### HU06 — Confirmação do pagamento

- [ ] A tela informa claramente que o pagamento foi registrado no protótipo.
- [ ] O valor e a data do pagamento aparecem na confirmação.
- [ ] A tela apresenta os próximos passos do cliente.
